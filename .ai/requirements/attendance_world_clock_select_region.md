# Requirements for Attendance World Clock Select Region

## 1. Background
Instead of static world clock panels, the user wants a select region dropdown option inside the attendance page clock-in section to display the live time for any selected international region.

## 2. Functional Requirements
- **Select Region Option**:
    - Add a `<select>` dropdown containing key world timezones/regions (e.g. New York, London, Tokyo, Dubai, Singapore, Dhaka, Kolkata, Sydney, Riyadh).
- **Interactive Live Clock Display**:
    - Render a single styled time display panel that dynamically shows the current time of the chosen timezone, updating live in real-time every second.
