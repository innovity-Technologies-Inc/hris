# Requirements for Attendance Header Primary Color Alignment

## 1. Background
The attendance page card header should match the project's primary brand color (the red/rose shade, `--primary-color: #974063`).

## 2. Functional Requirements
- **Header Color**:
    - Update the `.page-header` gradient background in `clock_in_out.blade.php` to use the primary brand color gradient (`#974063` transitioning to a darker shade `#6b2543`).
- **Glow & Highlights**:
    - Align clock highlights, text shadows, and radial glow colors to matching red shade tones (`rgba(151, 64, 99, ...)`).
