# Requirements for Attendance World Clock

## 1. Background
Employees want to view the country timezone of the main clock and have access to a world clock widget to monitor different international regions.

## 2. Functional Requirements
- **Local Country Tag**:
    - Detect the user's local timezone/country and render it as a badge next to the main "Current Time" header.
- **World Clock facility**:
    - Display key international region clocks (London, New York, Tokyo, Dubai) updating live in real-time.
- **Visual Design**:
    - Style the world clock cards using glassmorphic UI elements supporting light and dark modes.
